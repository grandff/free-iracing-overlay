# Free & Ultra-Lightweight iRacing Overlay

> **100% 영구 무료(Free & Open Source)** 이자 시스템 부하를 최소화한 **초경량(Ultra-Lightweight, RAM < 50MB, CPU < 1%)** 아이레이싱(iRacing) 전용 방송 그래픽 오버레이.

---

## 🌟 프로젝트 특징

1. **완전 무료 & 오픈소스**: 구독료 및 결제 유도 기능 전면 배제.
2. **초경량 네이티브 아키텍처**: 
   - **Tauri v2 + Rust**: Windows Shared Memory 제로 카피 매핑, GC 없는 마이크로초 틱 처리.
   - **Solid.js**: 가상 DOM 없는 컴포넌트 단위 반응형 DOM 갱신으로 60Hz 텔레메트리 렌더링 랙 제로.
   - **Windows 내장 WebView2**: 불필요한 번들 다운로드 없이 단일 바이너리(< 15MB) 구동.
3. **11대 핵심 기능 탑재**:
   - 순위표 (Leaderboard)
   - 렐러티브 (Relative - 내 기준 2~5대 설정)
   - 직전 랩타임 비교 (Last Lap Delta)
   - 리벤지 트래커 (사고 유발 드라이버 특정 및 갭 고정 추적)
   - 근접 스포터 (좌/우 독립 감지 거리 & 3단계 점멸)
   - 연료 시뮬레이터 (평균 소모량, 완주 필요량, 세이빙 타겟)
   - 타이어 분석기 (피트 확정치 + 주행 중 노면/부하 추정 모델)
   - 전방 사고 지점 경고 (내 전방 m 단위 잔여 거리 및 고휘도 점멸)
   - 날씨 & Tempest 정보 (풍향 나침반, 노면온도, 우천 강수량)
   - 멀티클래스 접근 경고 (상위 빠른 클래스 3초 이내 접근 경보)
   - **실시간 2D 트랙 맵 (Live Circuit GPS Overlay)**: 사고 섹터 옐로우 발광, 클래스별 차량 점, 리벤지 타깃 조준.
4. **5대 모터스포츠 방송 공식 테마 지원**:
   - **F1 (Formula 1)**: 다크 카본, F1 레드, 섹터별 미니 타임 바.
   - **WRC (World Rally Championship)**: 랠리 오렌지 & 네온 옐로우 고대비 스테이지 스플릿.
   - **WEC (World Endurance Championship)**: 르망 24h 다크 글래스모피즘, 클래스별 고유 배지.
   - **IndyCar**: 오픈휠 인디 블루 & 레드, P2P 카운터, 스피드 트랩.
   - **GT / Esports**: 네온 포인트, 미니멀리스트 e스포츠 카본 카드.
5. **초경량 벡터(SVG) 아이콘 시스템**:
   - 텍스트 의존을 줄이고 한눈에 상태를 파악할 수 있는 고해상도 인라인 SVG 아이콘 전면 적용.
