# Formula 1 Official WebFonts

To use the official proprietary Formula 1 typography, place the following font files in this folder (`public/fonts/`):

- `Formula1-Bold.woff2` (or `.woff`, `.ttf`)
- `Formula1-Regular.woff2` (or `.woff`, `.ttf`)
- `Formula1-Wide.woff2` (or `.woff`, `.ttf`)

If not present, the overlay automatically uses high-octane Google WebFonts (`Titillium Web` & `Chakra Petch`) which are loaded with zero configuration.
