# Free & Ultra-Lightweight iRacing Overlay - 마일스톤 로드맵 (Milestones)

이 문서는 아이레이싱(iRacing) 전용 **완전 무료 & 초경량 방송 그래픽 오버레이**의 개발 단계별 마일스톤 명세서입니다.  
사용자의 신규 UX 및 아키텍처 지침(설정 유무 확인 ➔ 설정 1: F1 테마 우선 선택 ➔ 설정 2: 미리보기 & `Alt + J` 배치/크기 조절 ➔ 최종 저장 & 기본값 사용)을 전면 반영하여 재구성되었습니다.

## 🚀 Milestone 1: 초기 설정 마법사 & F1 오버레이 배치/크기 에디터 (`Alt + J`)

> **목표:** 프로그램 설치/실행 시 최초 설정 유무를 확인하고, 테마 선택(F1 우선) ➔ 미리보기 및 `Alt + J` 크기/위치 조절 ➔ 최종 저장을 거쳐 기본값(Default)으로 관리하는 핵심 파이프라인을 완성합니다.

### 세부 작업 항목
- [x] **M1.1: 최초 실행 시 설정값 존재 여부 확인**
  - 로컬 스토리지에 기존 설정이 없으면 자동으로 **초기 설정 마법사(Setup Wizard)** 강제 진입.
  - 설정이 존재할 경우 설정 마법사를 건너뛰고 저장된 기본값으로 즉시 드라이빙 오버레이 구동.
- [x] **M1.2: 설정 1번 화면 - 테마 설정 화면**
  - 사용자에게 방송 그래픽 테마 선택 안내 (추후 언제든 재변경 가능 명시).
  - **핵심 요구사항:** 오직 **'F1 (Formula 1)' 테마만 활성화/선택 가능**하도록 구성.
  - 나머지 테마(WEC, WRC, IndyCar, GT)는 **'추후 제공(Coming Soon)'** 배지와 함께 비활성화 처리.
- [x] **M1.3: 설정 2번 화면 - 오버레이 미리보기 & 배치/크기 조절**
  - 테마 선택 시 실제 오버레이 위젯들의 실시간 미리보기 화면 제공.
  - **단축키 `Alt + J`**로 편집 모드를 켜고 끌 수 있도록 단축키 바인딩.
  - 마우스 드래그 앤 드롭으로 위젯 위치 이동 및 `+`/`-` 버튼으로 70%~150% 크기(Scale) 확대/축소.
- [x] **M1.4: 최종 저장 및 기본값(Default) 영구 관리**
  - [최종 저장 & 오버레이 시작] 버튼 클릭 시 설정값을 로컬에 영구 저장.
  - 이후 앱 재실행 시 항상 이 설정값이 기본값(Default)으로 자동 로드.
  - 상단 툴바의 [⚙️ 설정 마법사] 버튼을 통해 언제든 재설정 가능.
- [x] **M1.5: 60Hz 목업 텔레메트리 & 144Hz+ LERP 선형 보간 파이프라인**
  - macOS 개발 환경에서 즉시 검증 가능한 60Hz 가상 주행 엔진 내장.
  - 모니터 주사율에 맞춘 LERP 보간으로 144Hz 모니터 위에서 미세 떨림(Judder) 없는 렌더링.

### 완료 검증 기준 (DoD)
1. 첫 실행 시 설정 1번 화면(F1 테마 선택, 기타 테마 '추후 제공')이 정상 노출되는가?
2. 2번 화면에서 오버레이 미리보기가 뜨고 `Alt + J`로 편집 모드 토글 및 마우스 드래그/크기 조절이 가능한가?
3. [최종 저장]을 누르면 설정값이 저장되고, 페이지 새로고침 시 설정 마법사 없이 바로 저장된 위치/크기의 오버레이가 실행되는가?
4. 번들 크기 < 100KB, 빌드 시간 < 1초, 메모리 < 40MB를 엄격히 만족하는가?

## 🏎️ Milestone 2: F1 테마 전용 핵심 HUD 위젯 4종 구현

> **목표:** F1 방송 그래픽 스타일(다크 카본, F1 레드 `#E10600`, 볼드 고대비 폰트)로 가장 필수적인 기초 위젯 4종을 정밀 구현합니다.

### 세부 작업 항목
- [ ] **M2.1: 위젯 1 - F1 순위표 (Leaderboard)**
  - F1 중계 그래픽 스타일 클래스별 순위 정렬, 드라이버 약어, 피트 렌치 아이콘, 섹터 타임 미니바.
- [ ] **M2.2: 위젯 2 - F1 렐러티브 (Relative)**
  - 내 위치 기준 앞/뒤 근접 차량 간격 (사용자 설정: 2대 ~ 5대 조절 지원).
  - 동일 랩(White), 백마커(Blue), F1 타이어 컴파운드 배지(Soft Red, Medium Yellow, Hard White).
- [ ] **M2.3: 위젯 3 - F1 직전 랩타임 델타 (Lap Delta)**
  - F1 스플릿 타임 스타일 초 단위 델타 비교 (-0.23s 녹색, +0.42s 적색).
- [ ] **M2.4: 위젯 11 - 실시간 2D 트랙 맵 (Live Circuit Map)**
  - 2D SVG 서킷 레이아웃 위 실시간 차량 위치(내 차량 화살표 #1, 상대 차량 점).
  - 피트 레인 진입 차량 반투명화.
- [ ] **M2.5: 트리플 모니터(48:9) 뷰포트 센터 클램프**
  - 가로 5760x1080 / 7680x1440 환경에서 중앙 16:9 모니터 영역 안전 배치.

### 완료 검증 기준 (DoD)
1. 4개 위젯이 F1 공식 중계 특유의 폰트와 컬러로 60fps 실시간 갱신되는가?
2. 렐러티브의 표시 차량 수(2~5대) 조절이 정상 작동하는가?
3. 트리플 모니터 해상도에서도 화면 찢어짐 없이 1:1 픽셀 밀도를 유지하는가?

## 🛡️ Milestone 3: F1 테마 안전 및 레이스 관리 위젯 4종 구현

> **목표:** F1 디자인 언어에 맞춰 근접 스포터, 연료 시뮬레이터, 전방 사고 경고, 날씨 위젯을 완성합니다.

### 세부 작업 항목
- [ ] **M3.1: 위젯 5 - 근접 스포터 (Proximity Spotter)**
  - 좌/우 독립 감지 거리(1.5m~5m) 설정 및 거리별 3단계(안전/경고/위험) 점멸.
- [ ] **M3.2: 위젯 6 - 연료 시뮬레이터 (Fuel Calculator)**
  - 랩당 평균 소비량, 잔여 랩수 기준 완주 필요 연료량, 피트스탑 급유량 계산.
- [ ] **M3.3: 위젯 8 - 전방 사고 지점 경고 (Incident Hazard Meter)**
  - 전방 400m 이내 사고 감지 시 남은 거리(m) 실시간 카운트다운 & 고휘도 점멸.
- [ ] **M3.4: 위젯 9 - 날씨 & Tempest 정보 (Weather)**
  - 대기/노면 온도, 풍향 나침반, 우천 강수량 게이지.

### 완료 검증 기준 (DoD)
1. 좌/우 스포터가 독립된 감지 거리에 맞춰 개별 점멸하는가?
2. 연료 시뮬레이터가 랩 완료마다 연비를 오차 없이 갱신하는가?
3. 전방 차량 사고 시 즉각 m 단위 거리 경보가 발동하는가?

## 🧠 Milestone 4: F1 테마 고급 인텔리전스 3종 & 11대 전체 위젯 통합 완성

> **목표:** 리벤지 트래커, 타이어 분석, 멀티클래스 레이더를 완성하여 F1 테마 11대 전 기능을 유기적으로 통합합니다.

### 세부 작업 항목
- [ ] **M4.1: 위젯 4 - 리벤지 트래커 (Revenge Tracker)**
  - +4x 접촉 사고 유발 상대 드라이버 자동 감지 및 실시간 간격 고정 추적.
- [ ] **M4.2: 위젯 7 - 타이어 분석기 (Tire Analysis)**
  - 피트 진입 시 확정 데이터 + 주행 중 노면/부하 추정 모델 시각화.
- [ ] **M4.3: 위젯 10 - 멀티클래스 접근 경고 (Multiclass Radar)**
  - 상위 빠른 클래스 후방 3초 이내 접근 시 시각 경보.
- [ ] **M4.4: 트랙 맵 고급화**
  - 옐로우 플래그 섹터 발광 하이라이트 및 리벤지 타깃 조준선 오버레이.

### 완료 검증 기준 (DoD)
1. +4x 충돌 시뮬레이션 시 리벤지 대상이 정확히 락온되고 실시간 간격이 추적되는가?
2. 11대 위젯 전체가 F1 테마에서 조화롭게 구동되는가?

## 📦 Milestone 5: 차기 테마(WEC/WRC/Indy/GT) 확장 & Windows 단일 바이너리 패키징

> **목표:** F1 테마 완성 후 잠겨있던 4종 테마를 활성화하고, Windows Shared Memory 제로 카피 드라이버 연동 및 단일 포터블 바이너리를 패키징합니다.

### 세부 작업 항목
- [ ] **M5.1: 4종 차기 테마 순차 구현 및 활성화**
  - WEC 르망 24시, WRC 랠리, IndyCar 오픈휠, GT e스포츠 테마 정식 오픈.
- [ ] **M5.2: 실제 Windows iRacing Shared Memory 무지연 매핑 검증**
  - `Local\IRSDKMemMapFileName` 제로 카피 실시간 파싱.
- [ ] **M5.3: Windows 단일 독립 실행 파일(`.exe` / `.msi`) 빌드**
  - 번들 크기 < 15MB, 유휴 메모리 < 50MB, CPU < 1% 최종 벤치마크.

### 완료 검증 기준 (DoD)
1. 5개 테마 모두에서 11개 위젯이 완벽히 렌더링되는가?
2. 단일 실행 바이너리가 추가 런타임 없이 즉시 단독 실행되는가?
