사용자의 지시에 따라 각 마일스톤 단위로 작업을 수행하고 검증합니다.

## 🚀 Milestone 1: 프로젝트 기반 구축 & 가상 텔레메트리 파이프라인

> **목표:** 초경량 아키텍처 환경을 구성하고, macOS/Windows 모두에서 검증 가능한 60Hz 텔레메트리 파이프라인과 투명 오버레이 윈도우를 구현합니다.

### 세부 작업 항목
- [x] **M1.1: 프레임워크 스캐폴딩** (Tauri v2 + Solid.js + TypeScript + Tailwind CSS 완료, 번들 < 50KB)
- [x] **M1.2: 텔레메트리 연동 계층 추상화** (Win32 MMF reader + 60Hz mockEngine.ts 구현 완료)
- [x] **M1.3: 투명 오버레이 윈도우 제어** (투명 윈도우 설정, Ctrl+Shift+O 및 툴바 클릭스루 토글 완료)
- [x] **M1.4: 초경량 SVG 아이콘 베이스 시스템** (Icons.tsx 12종 인라인 SVG 구현 완료, 번들 0KB)
- [x] **M1.5: 고주사율(144Hz+) 대응 LERP 선형 보간 렌더 루프** (lerpEngine.ts V-Sync 보간 완료)

### 완료 검증 기준 (DoD)
1. 앱 실행 시 배경이 완전 투명한 상태로 게임/데스크톱 위에 최상단으로 렌더링되는가?
2. `Ctrl + Shift + O`로 마우스 클릭 통과/차단이 원활히 전환되는가?
3. 가상 텔레메트리 엔진이 60Hz 주기로 전송하고, 144Hz 모니터 위에서 LERP 보간으로 물 흐르듯 부드럽게 렌더링되는가?
4. CPU 점유율 < 1%, RAM 점유율 < 40MB를 엄격히 유지하는가?

## 🏎️ Milestone 2: 핵심 HUD 위젯 4종 & 테마 엔진 PoC

> **목표:** 실제 레이스에서 가장 필수적인 기초 위젯 4종과 F1/WEC 테마 전환을 구현하여 실시간 구동을 검증합니다.

### 세부 작업 항목
- [ ] **M2.1: 위젯 1 - 순위표 (Leaderboard)**
  - 세션 참가 차량 실시간 순위 정렬, 클래스 배지, 드라이버 이름, 베스트 랩타임, 피트 상태(Wrench 아이콘)
- [ ] **M2.2: 위젯 2 - 렐러티브 (Relative)**
  - 내 위치 기준 앞/뒤 근접 차량 시간 및 거리 간격 표시
  - 앞/뒤 표시 차량 수 조절 옵션 (2대 ~ 5대 슬라이더 지원)
  - 동일 랩(White), 랩다운/백마커(Blue), 클래스 색상 태그
- [ ] **M2.3: 위젯 3 - 직전 랩타임 델타 (Lap Delta)**
  - 직전 랩 대비 델타 초 단위 비교 ($\Delta = \text{MyLastLap} - \text{TargetLastLap}$)
  - 빠름(녹색 음수) / 느림(적색 양수) 셰브론 화살표 및 스톱워치 아이콘
- [ ] **M2.4: 위젯 11 - 실시간 2D 트랙 맵 기초 (Live Track Map)**
  - 서킷 레이아웃 2D 벡터(SVG) 렌더링
  - 내 차량(고휘도 시안 화살표) 및 경쟁 차량(클래스별 색상 점) 실시간 위치 표시
- [ ] **M2.5: 테마 엔진 프로토타입 (F1 vs WEC 테마)**
  - CSS Variables 기반 테마 토글러 구현 (F1 스타일 레드/카본 ↔ WEC 다크 글래스모피즘)
- [ ] **M2.6: 트리플 모니터(48:9) 뷰포트 대응 및 중앙 모니터 스냅 가이드**
  - 가로 5760x1080, 7680x1440 등 서라운드 해상도 감지 및 중앙 16:9 모니터 영역 기준 위젯 클램프(Clamp) 레이아웃

### 완료 검증 기준 (DoD)
1. 4개 위젯이 가상 주행 텔레메트리에 실시간(60fps)으로 부드럽게 반응하는가?
2. 렐러티브의 표시 차량 수(2~5대) 조절이 정상 작동하는가?
3. 테마 토글 시 렌더링 랙 없이 0ms로 스타일이 즉시 전환되는가?
4. 트리플 모니터(5760x1080 / 7680x1440) 해상도에서도 UI 비율 찢어짐 없이 중앙 모니터 시야각 내에 안정적으로 렌더링되는가?

## 🛡️ Milestone 3: 안전 및 레이스 관리 위젯 4종 구현

> **목표:** 레이스 중 사고 방지, 연료 관리, 기상 변화를 돕는 핵심 유틸리티 위젯 4종을 추가합니다.

### 세부 작업 항목
- [ ] **M3.1: 위젯 5 - 근접 스포터 (Proximity Spotter)**
  - 화면 좌/우 외곽에 차량 접근 감지 바 렌더링
  - 거리별 3단계 점멸 (안전 초록 → 주의 노랑 → 위험 빨강 고속 점멸)
  - **핵심 요구사항:** 좌측(Left) / 우측(Right) 독립 활성화 토글 및 민감도(1.5m ~ 5m) 개별 설정
- [ ] **M3.2: 위젯 6 - 연료 시뮬레이터 (Fuel Calculator)**
  - 최근 3~5랩 그린 플래그 기준 랩당 평균 소비량 ($L/\text{lap}$) 계산
  - 잔여 세션 시간/랩수 기반 완주 필요 연료량 및 피트 권장 주유량 계산 (Safety Margin $+1.5\text{L}$)
  - 연료 세이빙 모드 목표 소비량 제공
- [ ] **M3.3: 위젯 8 - 전방 사고 지점 경고 (Incident Hazard Meter)**
  - 전방 차량들의 코스 이탈(`OffTrack`), 속도 급감 감지
  - 내 전방 400m 이내 사고 발생 시 남은 거리(m) 실시간 카운트다운과 함께 고휘도 점멸 경보
- [ ] **M3.4: 위젯 9 - 날씨 & Tempest 정보 (Weather Widget)**
  - 실시간 대기 온도, 트랙 노면 온도, 풍속 및 풍향 나침반 인디케이터
  - iRacing Tempest 비(Rain), 강수량 게이지 및 노면 젖음 상태 시각화

### 완료 검증 기준 (DoD)
1. 좌/우 스포터가 독립된 감지 거리 임계값에 맞춰 각각 정확하게 점멸하는가?
2. 연료 시뮬레이터가 랩 완료마다 연비를 오차 없이 갱신하는가?
3. 가상 텔레메트리에서 전방 차량 스핀/사고 주입 시 즉각적인 잔여 거리(m) 점멸 경보가 발생하는가?

## 🧠 Milestone 4: 고급 인텔리전스 위젯 3종 & 5대 방송 테마 완성

> **목표:** 리벤지 트래커, 타이어 분석, 멀티클래스 접근 경고를 완성하고 5대 공식 방송 테마를 전면 적용합니다.

### 세부 작업 항목
- [ ] **M4.1: 위젯 4 - 리벤지 트래커 (Revenge Tracker)**
  - `PlayerCarDriverIncidents` 증가(+4x 접촉) 순간 반경 10m 이내 상대 차량 특정
  - 전용 HUD 박스에 상대 드라이버 이름, 차량 번호, 실시간 간격 고정 추적 및 타깃 조준선(`Crosshair`) 표시
- [ ] **M4.2: 위젯 7 - 타이어 분석기 (Tire Analysis)**
  - 피트 진입 시 확정 데이터(마모도, 내부 온도, 공기압) 표시
  - 주행 중에는 iRacing 제약을 우회하여 휠 슬립, 횡가속도, 노면온도 기반 '실시간 노면 부하 추정치' 시각화
- [ ] **M4.3: 위젯 10 - 멀티클래스 접근 경고 (Multiclass Radar)**
  - 상위 빠른 클래스 차량이 후방 3초 이내로 접근 시 시각 경보 및 상대 속도 델타 표시
- [ ] **M4.4: 5대 모터스포츠 완성형 테마 구현**
  1. **F1:** 다크 카본, F1 레드, 섹터별 미니 타임 바
  2. **WRC:** 랠리 오렌지 & 형광 옐로우 고대비 스테이지 스플릿
  3. **WEC:** 르망 24h 다크 글래스모피즘, Hypercar/LMP2/LMGT3 배지
  4. **IndyCar:** 인디 블루/레드, 원형 번호 라운델, P2P 카운터
  5. **GT / Esports:** 네온 시안/그린 포인트, 카본 텍스처
- [ ] **M4.5: 트랙 맵 고급 기능 완성**
  - 옐로우 플래그 발생 섹터 발광 하이라이트
  - 피트 진입 차량 반투명화 및 렌치 아이콘 표시
  - 리벤지 타깃 차량 위치에 타깃 조준선 오버레이

### 완료 검증 기준 (DoD)
1. +4x 충돌 시뮬레이션 시 리벤지 대상이 정확히 락온되고 실시간 간격이 추적되는가?
2. 5가지 테마 전환 시 11개 위젯 전체가 해당 모터스포츠 특유의 디자인으로 일관되게 변경되는가?

## 📦 Milestone 5: 위젯 커스텀 에디터 & 프로덕션 바이너리 패키징

> **목표:** 사용자가 마우스로 오버레이를 마음대로 배치할 수 있는 편집기와 영구 무료 단일 실행 바이너리를 완성합니다.

### 세부 작업 항목
- [ ] **M5.1: 위젯 레이아웃 편집기 (HUD Customizer)**
  - 편집 모드(`Ctrl + Shift + O`)에서 각 위젯을 드래그 앤 드롭으로 자유롭게 이동
  - 위젯별 크기(Scale), 불투명도(Opacity), 표시 On/Off 토글
  - **트리플 모니터 앵커링 설정:** 위젯별 기준 모니터(좌/중앙/우) 스냅, 근접 스포터 베젤 위치(중앙 베젤 vs 외곽 끝) 선택
  - 설정 내용을 로컬 JSON 파일에 자동 저장 및 불러오기
- [ ] **M5.2: 실제 Windows iRacing 환경 연동 검증**
  - 실제 iRacing 세션 구동 시 Windows Shared Memory 자동 감지 및 무지연 파싱 확인
- [ ] **M5.3: 성능 최적화 및 프로덕션 패키징**
  - 렌더링 틱 분리 (고속 위젯 60Hz, 정적 위젯 10~15Hz)
  - Windows 단일 독립 실행 파일(`.exe` / `.msi`) 빌드 파이프라인 구성 (< 15MB)
  - 최종 벤치마크: 메모리 < 50MB, CPU < 1% 달성 검증

### 완료 검증 기준 (DoD)
1. 사용자가 재부팅하거나 앱을 재시작해도 커스텀 위젯 위치와 테마 설정이 완벽히 복원되는가?
2. 1시간 이상 연속 구동 시 메모리 누수(Memory Leak)가 0인 것을 확인했는가?
3. 단일 실행 바이너리 실행 시 추가 설치 프로그램 없이 즉시 오버레이가 구동되는가?
