# Free & Ultra-Lightweight iRacing Overlay - 마일스톤 로드맵 (Milestones)

이 문서는 아이레이싱(iRacing) 전용 **완전 무료 & 초경량 방송 그래픽 오버레이**의 개발 단계별 마일스톤 명세서입니다.  
오버레이는 공통 범용 심레이싱 HUD 엔진으로 동작하며, F1/WEC/WRC/IndyCar/GT는 유저가 자유롭게 선택 가능한 스타일 테마입니다.

## 🚀 Milestone 1: 초기 설정 마법사 & 오버레이 배치/크기 에디터 (`Alt + J`)

> **목표:** 프로그램 설치/실행 시 최초 설정 유무를 확인하고, 테마 선택(F1 우선) ➔ 미리보기 및 `Alt + J` 크기/위치 조절 ➔ 최종 저장을 거쳐 기본값(Default)으로 관리하는 핵심 파이프라인을 완성합니다.

### 세부 작업 항목
- [x] **M1.1: 최초 실행 시 설정값 존재 여부 확인**
  - 로컬 스토리지에 기존 설정이 없으면 자동으로 **초기 설정 마법사(Setup Wizard)** 강제 진입.
  - 설정이 존재할 경우 설정 마법사를 건너뛰고 저장된 기본값으로 즉시 드라이빙 오버레이 구동.
- [x] **M1.2: 설정 1번 화면 - 테마 설정 화면**
  - 사용자에게 방송 그래픽 테마 선택 안내 (추후 언제든 재변경 가능 명시).
  - 현재는 'F1' 스타일 테마 우선 활성화, 나머지 테마(WEC, WRC, IndyCar, GT)는 '추후 제공'으로 잠금.
- [x] **M1.3: 설정 2번 화면 - 오버레이 미리보기 & 배치/크기 조절**
  - 테마 선택 시 실제 오버레이 위젯들의 실시간 미리보기 화면 제공.
  - **단축키 `Alt + J`**로 편집 모드를 켜고 끌 수 있도록 단축키 바인딩.
  - 마우스 드래그 앤 드롭으로 위젯 위치 이동 및 크기(Scale) 확대/축소.
- [x] **M1.4: 프로그램 제어판(`ControlApp.tsx`) 분리 & 7개 국어 다국어 지원**
  - 인게임 투명 오버레이와 프로그램 설정 제어판 완전 분리.
  - 한국어 기본 + 영어, 중국어, 일본어, 프랑스어, 독일어, 이탈리아어 7개 국어 지원.
- [x] **M1.5: 최종 저장 및 기본값(Default) 영구 관리 (`config.json`)**
  - [최종 저장] 시 `config.json` 및 `localStorage` 영구 보존.

## 🏎️ Milestone 2: 핵심 HUD 위젯 4종 구현 (순위표 / 상대 간격 / 직전 랩 델타 / 2D 트랙 맵)

> **목표:** 방송 그래픽 스타일(다크 카본, 타이밍 셰브론, 볼드 고대비 폰트)로 가장 필수적인 기초 위젯 4종을 정밀 구현합니다.

### 세부 작업 항목
- [ ] **M2.1: 위젯 1 - 순위표 (Leaderboard / Standings)**
  - **기본 데이터:** `(순위) (국가) (차량브랜드) (이름) (SR) (IR) (베스트랩타임) (최근랩타임)` 기준.
  - **1등 시작 고정:** 무조건 1등(P1)부터 순차 정렬 시작.
  - **너비 반응형 순차 노출 계층:**
    - 최소 너비: `(순위) (이름) (최근랩타임)`
    - 너비 확장 1: `+ (베스트랩타임)`
    - 너비 확장 2: `+ (IR)`
    - 너비 확장 3: `+ (국가)`
    - 너비 확장 4: `+ (SR)`
    - 너비 확장 5: `+ (차량브랜드)`
  - **SR(Safety Rating) 배지:** R, D, C, B, A, P 라이선스별 색상 및 글자 주변 radius 사각형 배지.
  - **테마 적용:** F1 하드코딩 로고 일체 배제, 선택한 테마 스타일에 맞춘 레이아웃 렌더링.
- [ ] **M2.2: 위젯 2 - 렐러티브 (Relative)**
  - 내 위치 기준 앞/뒤 근접 차량 간격 (사용자 설정: 2대 ~ 5대 조절 지원).
  - 동일 랩(White), 백마커(Blue), 타이어 컴파운드 배지(Soft Red, Medium Yellow, Hard White).
- [ ] **M2.3: 위젯 3 - 직전 랩타임 델타 (Lap Delta)**
  - 초 단위 델타 비교 (-0.23s 녹색, +0.42s 적색).
- [ ] **M2.4: 위젯 11 - 실시간 2D 트랙 맵 (Live Circuit Map)**
  - 2D SVG 서킷 레이아웃 위 실시간 차량 위치(내 차량 화살표 #1, 상대 차량 점).
  - 피트 레인 진입 차량 반투명화.
- [ ] **M2.5: 트리플 모니터(48:9) 뷰포트 센터 클램프**
  - 가로 5760x1080 / 7680x1440 환경에서 중앙 16:9 모니터 영역 안전 배치.

## 🛡️ Milestone 3: 안전 및 레이스 관리 위젯 4종 구현

> **목표:** 모터스포츠 디자인 언어에 맞춰 독립 좌/우 근접 스포터, 연료 시뮬레이터, 전방 사고 경고, 날씨 위젯을 완성합니다.

### 세부 작업 항목
- [ ] **M3.1: 위젯 5 - 독립 좌/우 근접 스포터 (Proximity Spotter)**
  - 좌측/우측 개별 위젯 분리, 독립 감지 거리(1.5m~5m) 설정 및 거리별 3단계(안전/경고/위험) 점멸.
- [ ] **M3.2: 위젯 6 - 연료 시뮬레이터 (Fuel Calculator)**
  - 랩당 평균 소비량, 잔여 랩수 기준 완주 필요 연료량, 피트스탑 급유량 계산.
- [ ] **M3.3: 위젯 8 - 전방 사고 지점 경고 (Incident Hazard Meter)**
  - 전방 400m 이내 사고 감지 시 남은 거리(m) 실시간 카운트다운 & 고휘도 점멸.
- [ ] **M3.4: 위젯 9 - 날씨 & Tempest 정보 (Weather)**
  - 대기/노면 온도, 풍향 나침반, 우천 강수량 게이지.

### 세부 작업 항목
- [ ] **M5.1: 4종 차기 테마 순차 구현 및 활성화**
  - WEC 르망 24시, WRC 랠리, IndyCar 오픈휠, GT e스포츠 테마 정식 오픈.
- [ ] **M5.2: 실제 Windows iRacing Shared Memory 무지연 매핑 검증**
  - `Local\IRSDKMemMapFileName` 제로 카피 실시간 파싱.
- [ ] **M5.3: Windows 단일 독립 실행 파일(`.exe` / `.msi`) 빌드**
